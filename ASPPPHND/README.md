# ASPPPHND public IPA releases

This directory contains public binary IPA releases only. The ASPPPHND source code is maintained in a private repository.

## 4.5.55 (build 90)

- Minimum iOS: 15.0
- Package: `ASPPPHND-4.5.55-build90-trollstore.ipa`
- Intended for TrollStore/jailbreak-compatible installation.
- **Tải IPA ngay** now keeps the Versions sheet open and shows preparation, live percentage/speed, completion, or failure.
- **Tải qua ID Apple** still prefers the native App Store client; when iOS has no active StoreKit client context it automatically falls back to the saved/selected Apple ID download path instead of stopping with the client-context error.
- Source code remains private.
- SHA-256: see `SHA256SUMS.txt`.

## 4.5.54 (build 89)

- Minimum iOS: 15.0
- Package: `ASPPPHND-4.5.54-build89-trollstore.ipa`
- Intended for TrollStore/jailbreak-compatible installation.
- Version history now offers two actions when a version is selected:
  - **Tải IPA ngay** — keeps the existing ASPPPHND IPA download flow.
  - **Tải qua ID Apple** — submits the selected `externalVersionID` through the device's native App Store/StoreKit session.
- Source code remains private.
- SHA-256: see `SHA256SUMS.txt`.
